# Galerie hyperviseurs — descripteurs d'actions de provisioning.
# Un sous-dossier par hyperviseur ; le chemin du descripteur est relatif à ce toc.
# Le dossier porte déjà le nom de l'hyperviseur : les fichiers ne le répètent pas.
# Format : chemin/descripteur.json | hyperviseur | action | description
# L'URL de chaque descripteur est saisie à la main dans la config du portail
# (HypervisorType.add_script / destroy_script) — pas d'import automatique.
# Un même script peut servir plusieurs descripteurs : vm-memory.sh porte
# l'ajout et le retrait, qui ne diffèrent que par le signe du delta.
# Fichier compagnon non listé ici : proxmox/harden-networkd.sh, récupéré au
# runtime par clone-vm-node.sh (étape A.10c) et non par le portail.
proxmox/clone-vm-node.json | proxmox | create_vm | Clone un template cloud-init et configure un nœud Docker (étapes A.1–A.11)
proxmox/destroy-vm-node.json | proxmox | destroy_vm | Arrête et supprime une VM Proxmox par son VMID
proxmox/vm-disk-add.json | proxmox | vm_disk_add | Agrandit le disque d'une VM (+10G) — un disque ne se réduit pas
proxmox/vm-memory-add.json | proxmox | vm_memory_add | Ajoute 1024 Mo de mémoire à une VM
proxmox/vm-memory-sub.json | proxmox | vm_memory_sub | Retire 1024 Mo de mémoire à une VM
